# 付録: サーバーを立てずに済ませる方法(iOSショートカット)

方法C(このリポジトリのスクリプト)は「あと◯分・あと◯停留所」を判定してプッシュ通知まで自動化できますが、**日本で常時動くマシン**が要ります。
「そこまでは要らない、毎朝あの画面がパッと出れば十分」なら、スマホだけで完結するこちらが手軽です。地域制限も自分のスマホ(日本)で開くので問題になりません。

## iPhone(ショートカット + オートメーション)

1. 「ショートカット」アプリ →「オートメーション」タブ → `+` →「時刻」
2. 時刻を **6:25**、頻度「毎日」に設定
3. 動作を追加 →「URLを開く」→ 接近情報のURLを貼り付け:
   ```
   https://transfer-cloud.navitime.biz/nagasaki-bus/approachings?departure-busstop=00410505&pole=000000001062
   ```
4. 「実行前に尋ねる」を **オフ**(iOS 15以降なら通知だけで自動実行できます)

これで毎朝6:25に接近情報ページが自動で開きます。

## Android(Tasker など)

- Tasker で `Time` プロファイル(6:25)→ `Browse URL` に同じURL、で同等のことができます。
- 標準機能だけなら、ホーム画面にこのURLのショートカットを置いておくだけでもワンタップで開けます。

---

### どちらを使う?

| | 方法C(スクリプト) | iOSショートカット |
|---|---|---|
| プッシュ通知(あと◯分) | ○ 自動判定して通知 | × 画面が開くだけ |
| 常時稼働マシン | 必要(日本) | 不要 |
| 手間 | 中 | 小 |
